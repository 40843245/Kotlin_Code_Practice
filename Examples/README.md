# Kotlin
## example code
### requisite
1. You must have these things to execute the projects or code snippets in koltin.

+ Kotlin IDE
+ Kotlin IDE for project (such as `IntellJ`): since some examples are a project that needs to execute it with project.
+ LTS (Long term support) version of JVM
+ LTS (Long term support) version of JDK, JRE etc.

> [!NOTE]
> When install Kotlin IDE for project, it usually installs LTS version of JVM, JDK, and JRE etc.

> [!IMPORTANT]
> If you only have a lightweight IDE (such as `VSC`) and one installs a plugin about koltin, the code snippets can only be executed.
>
> To execute a project, install Kotlin IDE for project (such as `IntellJ`).


> [!TIP]
> About Kotlin IDE for project, I highly recommend to install `IntelliJ` instead of `Eclipse`.

2. To execute the code, you must familar with at least these skills.

+ operate on UI with Kotlin IDE.
+ operate on UI with Kotlin IDE for project. (including how to check and choose JVM, JDK, and JRE version etc).

### To fully understand about project or code snippets

> [!IMPORTANT]
> To fully understand about project or code snippets, I highly recommend to do these things.
> + Try to compile the code then execute the code (if compile success), see the outputs or exception at runtime. Otherwise (compile fails), see the error messsage. ***AND think why it is.***
>
> + If you don't understand a keyword the code snippets, you can search the keyword in Kotlin official Docs or Kotlin API references.
>
> About how to search it, see [the tips in reference section under reference.md](https://github.com/40843245/Kotlin_Code_Practice/blob/main/reference.md)
