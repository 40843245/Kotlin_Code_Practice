# Kotlin
## reference
### Kotlin official docs
See [Kotlin official docs](https://kotlinlang.org/docs/home.html)

> [!TIP]
> To search specific topic in `Kotlin official docs`, type related term followed by `in Kotlin`  in search query box under webbrowser then search it.
>
> For example, I want to see `high order function` in Kotlin, I can type `high order function in Kotlin` in search query box under webbrowser.

### Kotlin API reference
See [Kotlin API reference](https://kotlinlang.org/api/latest/jvm/stdlib/)

> [!TIP]
> To search specific method or class etc in `Kotlin API reference`, type the term followed by `in Kotlin` in search query box under webbrowser then search it.
>
> For example, I want to see `any` method in Kotlin, I can type `any in Kotlin` in search query box under webbrowser.
